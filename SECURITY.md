# Security Policy

## 🛡️ Reporting Vulnerabilities & False Positives

**SENTINEL_OS** is an educational simulator designed to teach users about web security and phishing detection.

If you discover a false positive/negative scenario in `data.js`, a logic flaw in the URL parser, or a vulnerability within the simulator itself, please follow the guidelines below:

### How to Report

1. **Do NOT open a public issue** if you discover a security flaw that could compromise local web storage or runtime execution.
2. Submit your findings directly via GitHub Security Advisories or contact the maintainers.
3. Provide a brief description of the scenario, the expected domain structure, and the actual behavior.

Thank you for helping keep **SENTINEL_OS** safe, realistic, and accurate!
