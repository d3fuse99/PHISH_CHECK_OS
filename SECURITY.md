# Security Policy

## 🛡️ Vulnerability Disclosure & False Positive Reporting

**SENTINEL_OS** is an educational cybersecurity simulator designed to train users in identifying web threats and phishing attacks.

### Scope & Guidelines
If you discover a false positive/negative scenario in `data.js`, a logic flaw in the detection engine, or a security issue in the simulator itself, please report it securely.

### How to Report
1. **Do NOT open a public GitHub issue** for undisclosed security vulnerabilities.
2. Submit your report directly via **GitHub Security Advisories** or contact the repository owner.
3. Response SLA: All reported advisories will be acknowledged within 24 hours.

### Supported Versions
| Version | Status             |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

Thank you for helping keep **SENTINEL_OS** safe and accurate!
