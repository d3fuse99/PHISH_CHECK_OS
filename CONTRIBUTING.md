# Contributing Guidelines for SENTINEL_OS

Thank you for helping improve **SENTINEL_OS**! We welcome contributions from developers, security researchers, and cybersecurity enthusiasts.

## Commit Message Conventions
Please format your commit messages using Conventional Commits:
* `feat:` — New feature or phishing brand scenario
* `fix:` — Bug fix or false positive scenario correction
* `docs:` — Documentation and Markdown updates
* `style:` — CSS design and UI layout styling
* `refactor:` — Code structure refactoring without behavior changes

## Code Quality Standards
* Do not leave Russian language comments inside JavaScript, HTML, or CSS code.
* Ensure all new scenario strings are localized in both English (`errEn`) and Russian (`errRu`).
* Test all changes locally across Easy, Medium, and Hard difficulty levels before submitting a PR.
